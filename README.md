# 仿欧陆词典阅读器

模仿欧陆词典阅读器风格的安卓双语阅读原型应用。

## 功能

- **深色阅读界面**：黑底白字，适合夜间阅读
- **书架页**：显示示例书籍，支持导入
- **导入书籍**：点击右上角「导入」按钮，弹出选项列表，可选择导入 **TXT** 或 **EPUB** 文件
- **AI 翻译按钮**：阅读页右上角蓝色「中A」按钮，点击后模拟 AI 翻译并显示中文译文
- **底部导航**：目录 / 书签 / 笔记 / 搜索（功能占位）

## 使用方法

1. 打开应用，默认显示示例书籍《The Lord of the Rings》
2. 点击右上角「导入」→ 选择「TXT」或「EPUB」→ 选择文件 → 自动进入阅读页
3. 阅读时点击右上角「中A」按钮触发翻译
4. 再次点击可隐藏/显示译文

## 编译与安装

- 最低支持 Android 7.0 (API 24)
- 用 Android Studio 打开 `EudicReader` 文件夹
- 点击 Run 即可编译安装

## 说明

当前为原型版本，翻译为模拟延迟（约 1.2 秒），实际内容为预置译文。EPUB 导入会提取书中的文本内容（去除 HTML 标签）。完整的在线 AI 翻译、笔记高亮等功能可继续扩展。
